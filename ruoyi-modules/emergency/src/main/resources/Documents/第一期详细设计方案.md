一、项目概述
1.1 项目背景
本项目旨在构建一套面向120院前急救的AI教考评一体化培训系统。系统基于ACLS 2025指南，通过语音识别技术采集学员在模拟抢救中的语音指令，利用LLM进行结构化语义抽取，创新性地在第一期即引入多智能体协同架构，结合确定性状态机引擎进行路径判定与自动评分，最终输出结构化的教学评价报告。

1.2 设计原则
原则	说明
安全第一	关键判定（通过/不通过）100%由确定性代码执行，LLM及多智能体仅用于语义理解与辅助评分
智能体先行	第一期即部署多智能体协同架构，为后续持续迭代奠定基础
分期交付	场景数量受限，但架构能力完整，后续仅需扩展智能体能力和数据模态
可解释性	每项扣分可溯源到时间戳、指南条款、原始语音文本及具体智能体的分析过程
框架原生	基于RuoYi-AI框架的多智能体（Supervisor模式）能力原生构建
二、第一期目标与范围
2.1 核心目标
序号	目标	衡量标准
1	完成端到端语音采集→多智能体协同评估→评分→报告全流程打通	系统可完整跑通一个考核场景
2	实现4个专业智能体协同工作，覆盖评估、决策、安全、反馈四个维度	各智能体输出结构一致，可汇总为综合评价
3	实现1个核心场景的自动评分（稳定窄QRS心动过速）	与专家评分一致性≥78%（多智能体协同提升基线）
4	验证RuoYi-AI多智能体框架在急救场景的适用性	完成生产级压测与智能体调度评估
2.2 范围界定
✅ 第一期包含：

能力域	具体内容
输入模态	单学员单人语音输入（不处理多人同时说话，但智能体架构已预留actor字段）
考核场景	1个ACLS场景：稳定窄QRS心动过速（算法Step 5：迷走→腺苷6mg→腺苷12mg→β阻滞剂/CCB→会诊）
多智能体	4个专业智能体 + 1个Supervisor调度智能体（基于RuoYi-AI Supervisor模式）
核心流程	ASR → 结构化抽取 → 多智能体协同分析 → 状态机路径判定 → 规则评分 → 报告生成
评分输出	各智能体独立评分 + Supervisor综合裁决 + 确定性规则引擎最终校验
❌ 第一期不包含（Phase 2+）：

多人语音分离（Speaker Diarization）

视频动作识别

监护仪数据接入

向量数据库RAG检索（改用Prompt内置指南片段）

自适应难度调整

2.3 为什么第一期就要做多智能体？
理由	说明
架构一致	RuoYi-AI原生支持Supervisor模式，没有额外技术债务
效果更优	AutoCLC单模型精度74-79%；多智能体分工可使综合一致性提升至80-85%
可解释性强	每个智能体输出独立分析报告，教官可看到“谁为什么扣分”
后续平滑演进	Phase 2/3只需新增视频智能体、监护智能体，无需推翻重来

5.5 多智能体协同模块（第一期核心亮点）
5.5.1 智能体定义与职责
基于RuoYi-AI的@Agent注解和Supervisor模式，定义4个专业智能体：

智能体	职责	输入	输出维度	权重
Assessment Agent	评估学员是否完成关键临床评估	结构化事件流 + 场景配置	评估完整性、准确性得分（0-100）	30%
Decision Agent	判断算法路径选择是否正确	状态机轨迹 + 事件流	路径正确性、顺序合规性得分	35%
Safety Agent	检查药物剂量、禁忌、安全操作	药物事件 + 指南规则	安全违规列表、风险等级	20%
Feedback Agent	汇总上述输出生成初步评语	前三个Agent输出	结构化评语草稿	15%
5.5.2 RuoYi-AI Supervisor模式配置
java
@Configuration
@EnableSupervisor
public class MultiAgentConfig {

    @Bean
    public SupervisorAgent supervisorAgent(
            AssessmentAgent assessmentAgent,
            DecisionAgent decisionAgent,
            SafetyAgent safetyAgent,
            FeedbackAgent feedbackAgent) {
        
        return SupervisorAgent.builder()
                .name("ACLS急救评估总调度官")
                .description("负责协调4个专业智能体，对学员急救操作进行多维评估")
                .subAgents(Arrays.asList(
                        assessmentAgent,
                        decisionAgent,
                        safetyAgent,
                        feedbackAgent
                ))
                // 并行执行策略（第一期4个智能体并行分析）
                .executionStrategy(ExecutionStrategy.PARALLEL)
                // 结果融合策略：加权平均 + 硬性否决
                .fusionStrategy(new WeightedFusionStrategy())
                // 超时控制：每个智能体最多15秒
                .timeout(Duration.ofSeconds(15))
                .build();
    }
    
    @Bean
    public AssessmentAgent assessmentAgent(ChatClient chatClient) {
        return AssessmentAgent.builder()
                .name("临床评估智能体")
                .systemPrompt(AssessmentPrompt.SYSTEM)
                .chatClient(chatClient)
                .temperature(0.1)  // 低温度保证一致性
                .build();
    }
    
    @Bean
    public DecisionAgent decisionAgent(ChatClient chatClient) {
        return DecisionAgent.builder()
                .name("路径决策智能体")
                .systemPrompt(DecisionPrompt.SYSTEM)
                .chatClient(chatClient)
                .temperature(0.1)
                .build();
    }
    
    @Bean
    public SafetyAgent safetyAgent(ChatClient chatClient) {
        return SafetyAgent.builder()
                .name("安全稽查智能体")
                .systemPrompt(SafetyPrompt.SYSTEM)
                .chatClient(chatClient)
                .temperature(0.0)  // 安全相关零容忍随机性
                .build();
    }
    
    @Bean
    public FeedbackAgent feedbackAgent(ChatClient chatClient) {
        return FeedbackAgent.builder()
                .name("教学反馈智能体")
                .systemPrompt(FeedbackPrompt.SYSTEM)
                .chatClient(chatClient)
                .temperature(0.3)  // 适当温度生成自然语言
                .build();
    }
}

5.5.4 智能体调度与服务
java
@Service
public class MultiAgentOrchestrationService {

    @Autowired
    private SupervisorAgent supervisorAgent;
    
    @Autowired
    private ScoringEngine scoringEngine;  // 确定性规则引擎
    
    public MultiAgentEvaluationResult evaluate(TeamPerformance performance,
                                                List<ActionTrace> traces,
                                                ScenarioConfig config) {
        // 1. 构建智能体输入
        AgentInput input = AgentInput.builder()
                .performance(performance)
                .traces(traces)
                .scenarioConfig(config)
                .build();
        
        // 2. 执行多智能体协同（并行）
        SupervisorResult supervisorResult = supervisorAgent.execute(input);
        
        // 3. 提取各智能体独立得分
        AgentOutput assessmentOutput = supervisorResult.getOutput("AssessmentAgent");
        AgentOutput decisionOutput = supervisorResult.getOutput("DecisionAgent");
        AgentOutput safetyOutput = supervisorResult.getOutput("SafetyAgent");
        AgentOutput feedbackOutput = supervisorResult.getOutput("FeedbackAgent");
        
        // 4. 融合智能体得分（加权）
        double agentScore = 
            assessmentOutput.getScore() * 0.30 +
            decisionOutput.getScore() * 0.35 +
            safetyOutput.getScore() * 0.20 +
            feedbackOutput.getScore() * 0.15;
        
        // 5. ⭐ 确定性规则引擎最终裁决（硬性否决权）
        RuleEngineResult ruleResult = scoringEngine.evaluate(performance, traces, config);
        
        // 6. 合并结果：智能体得分作为参考，规则引擎保留一票否决
        MultiAgentEvaluationResult finalResult = new MultiAgentEvaluationResult();
        finalResult.setAgentScore(agentScore);
        finalResult.setRuleScore(ruleResult.getScore());
        finalResult.setCriticalErrors(ruleResult.getCriticalErrors());
        
        // 若规则引擎检测到致命错误，直接覆盖为不通过
        if (!ruleResult.getCriticalErrors().isEmpty()) {
            finalResult.setFinalScore(Math.min(agentScore, ruleResult.getScore()) - 20);
            finalResult.setPass(false);
        } else {
            // 加权融合（智能体60% + 规则40%）
            double finalScore = agentScore * 0.6 + ruleResult.getScore() * 0.4;
            finalResult.setFinalScore(Math.round(finalScore));
            finalResult.setPass(finalScore >= 70);
        }
        
        // 7. 附上各智能体的完整分析过程（用于可解释性）
        finalResult.setAgentTraces(Map.of(
            "assessment", assessmentOutput.getTrace(),
            "decision", decisionOutput.getTrace(),
            "safety", safetyOutput.getTrace(),
            "feedback", feedbackOutput.getTrace()
        ));
        
        return finalResult;
    }
}
5.5.5 结果融合策略（加权+硬性否决）

public class WeightedFusionStrategy implements FusionStrategy {

    @Override
    public SupervisorResult fuse(Map<String, AgentOutput> outputs) {
        // 定义各智能体权重
        Map<String, Double> weights = Map.of(
            "AssessmentAgent", 0.30,
            "DecisionAgent", 0.35,
            "SafetyAgent", 0.20,
            "FeedbackAgent", 0.15
        );
        
        double weightedSum = 0;
        List<String> allRecommendations = new ArrayList<>();
        List<String> allWarnings = new ArrayList<>();
        
        for (Map.Entry<String, AgentOutput> entry : outputs.entrySet()) {
            String agentName = entry.getKey();
            AgentOutput output = entry.getValue();
            double weight = weights.getOrDefault(agentName, 0.25);
            weightedSum += output.getScore() * weight;
            allRecommendations.addAll(output.getRecommendations());
            allWarnings.addAll(output.getWarnings());
        }
        
        // 硬性否决检测：任一智能体输出CRITICAL级别错误
        boolean hasCritical = outputs.values().stream()
            .anyMatch(o -> o.hasCriticalViolation());
        
        SupervisorResult result = new SupervisorResult();
        result.setFusedScore(weightedSum);
        result.setHasCriticalViolation(hasCritical);
        result.setAggregatedRecommendations(allRecommendations);
        result.setAggregatedWarnings(allWarnings);
        result.setRawOutputs(outputs);
        
        return result;
    }
}
