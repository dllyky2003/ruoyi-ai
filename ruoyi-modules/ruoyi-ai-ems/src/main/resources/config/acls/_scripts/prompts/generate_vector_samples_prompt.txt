你是急救医疗 (EMS) 领域的专家，正在为一个意图识别系统的【向量匹配模块】生成中文训练样本。

【说话人视角】
所有样本都必须是【急救团队组长 / 现场指挥】的口吻，即组长对队员下达指令、布置任务、
确认动作、协调分工、复盘状态时可能说出的原话。不要用患者本人、家属、路人、
或医院医生的口吻。

【目标意图】
- 编码: $intent_code
- 名称: $name_cn
- 标准动作描述: $standard_script
- 关键词参考: $keywords
- 已有少量示例（可参考风格，但不要照抄）:
$examples

【任务】
生成 $n 条高质量、多样化的中文自然语言样本，用于向量相似度匹配训练。

【硬性要求】
1. 每条样本都是急救团队组长在真实出诊/抢救现场可能脱口而出的指挥语。
2. 表达必须多样，覆盖以下风格：
   - 短促命令式：摸一下脉搏 / 准备电击 / 打开气道
   - 分工指派式：你负责量血压 / 谁来准备球囊面罩
   - 确认复述式：脉搏摸到了吗 / 血压读数多少 / 再确认一遍
   - 带场景的复合句：他现在没反应先检查呼吸再摸脉
   - 带语气词的现场口语：快摸脉 / 先别动等我确认
   - 流程衔接式：呼吸查完接着量血压 / 按压别停我来摸脉
3. 覆盖同义词、近义短语、不同句式（陈述句、祈使句、疑问句）。
4. 每条样本必须只指向【目标意图】，不要与其他意图混淆（例如"检查脉搏"不要写成"检查呼吸"）。
5. 不要出现"正例/负例/示例"等标记，不要带【】括号。
6. 每条样本独立完整，不带编号、不带解释、不带引号。
7. 【不要出现任何标点符号】，包括句号、逗号、顿号、问号、感叹号、分号、冒号、
   引号、括号、省略号。
8. 【句子中间不要有空格】，整条样本是一串连续的中文字符，从头连到尾。
9. 【不要出现任何人名】，包括"小王""老李""张三"这类具体称呼，也不要出现真实
   姓名。需要指代队友时，统一用"你""你们""谁来""有人"这类不定指的词。

【输出格式】
只输出一个 JSON 数组，例如：
["摸一下颈动脉看有没有脉","先别按压我确认一下脉搏","脉搏摸到了吗报一下","快摸颈动脉"]

不要输出 markdown 代码块，不要输出任何额外文字或说明。
