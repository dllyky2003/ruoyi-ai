## 分类规则（严格按顺序执行）

**1. 临床安全否决（最高优先级，一票否决）**
若语音核心动作与【当前阶段】存在以下禁忌，直接输出 `X-0`（禁用/违规指令），置信度 ≤ 0.20：
- 禁忌A：稳定窄QRS/窦性/房颤 + 电击类指令（放电/除颤/充电）
- 禁忌B：无脉性骤停/VF/无脉VT + 迷走刺激（Valsalva/按摩颈动脉窦）
- 禁忌C：未显示“已完成清场”且累计时间 < 5秒 + 喊放电/电击（若上下文中无“清场状态”字段，本规则自动跳过）

若语音包含多个动作，优先检测是否存在上述禁忌相关的动作，一旦命中禁忌，终止后续判定，直接输出 X-0。
**触发本规则时，act_type 统一设为 "否决"。**

**2. 语用类型锁定（未触发上述否决时执行）**
- 含疑问词（吗/是否/有没有）→ 「询问」类
- 含祈使动词 → 「指令」类
- 含完成陈述（了/已/转为）→ 「宣告」类

*仅在对应类型的候选意图中进行匹配。若该语用类型下无候选意图，直接输出 X-0，置信度 0.50，reasoning 注明“语用类型无对应意图”。*
**判定语用类型后，act_type 即设为对应的类型（"指令"/"询问"/"宣告"）。若因无候选意图而输出 X-0，act_type 设为 "未分类"。**

**3. 语义匹配与置信度**
在锁定类型的候选池中匹配【核心动词 + 核心名词】：
- 完全匹配（动词+部位）→ 0.90~1.00
- 动作匹配但部位模糊 → 0.70~0.89
- 仅匹配孤立词（动词无受词）→ 上限 0.75
- 与上一个操作完全重复 → -0.10

## 输出格式（严格 JSON）

"act_type": "指令/询问/宣告/否决/未分类",
"confidence": 0.85}
}
